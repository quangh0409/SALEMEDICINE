🧩 1. Yêu cầu chức năng (Functional Requirements)
🏬 Quản lý sản phẩm (Product Management)

CRUD sản phẩm: mã, tên, giá, đơn vị tính, tồn kho.

Cho phép nhập hàng (nhập kho).

Cho phép xuất hàng (bán hàng, trừ tồn).

👥 Quản lý khách hàng (Customer Management)

CRUD khách hàng: mã KH, họ tên, số điện thoại, email, địa chỉ.

🧾 Quản lý hóa đơn / bán hàng (Invoice)

Tạo hóa đơn bán hàng (có danh sách sản phẩm, số lượng, tổng tiền).

Cho phép in hóa đơn / xuất PDF hoặc JSON.

📦 Quản lý tồn kho (Inventory)

Cập nhật tồn kho tự động sau mỗi giao dịch nhập / xuất.

Xem danh sách sản phẩm tồn dưới ngưỡng cảnh báo.

🖨️ Chuẩn bị tích hợp thiết bị ngoại vi

Thiết kế backend & frontend dễ mở rộng cho:

Máy quét mã vạch (barcode scanner).

Máy in hóa đơn (POS printer).

⚙️ 2. Backend yêu cầu kỹ thuật (NestJS + Oracle)

Công nghệ:

NestJS (TypeScript)

TypeORM + Oracle Database

Swagger cho tài liệu API

Class-validator, Class-transformer

DTO, Mapper pattern, Repository pattern

Clean code theo SOLID principles

Mô hình cơ bản:

BaseEntity: id, createdAt, updatedAt, createdBy, updatedBy

ApiResponse<T>: chuẩn hóa response

ExceptionFilter: xử lý lỗi tập trung

LoggerInterceptor: log input/output

Ví dụ API chính:

POST /products/import

POST /products/export

GET /products

POST /customers

GET /invoices/:id

POST /invoices/print

Bảo mật & Mở rộng:

Có module Auth (JWT + Guard + Role-based Access Control).

Hỗ trợ Pagination, Filtering, Sorting.

Viết README.md hướng dẫn chạy và test API bằng Postman hoặc Swagger.

Products

Customers

Sales / Invoices

Trang Products:

Bảng hiển thị sản phẩm (tên, mã, giá, tồn).

Nút “Nhập hàng” và “Xuất hàng”.

Form có validation rõ ràng.
